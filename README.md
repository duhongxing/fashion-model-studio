# Fashion Model Studio — 前端原型

打开 `index.html` 即可使用。支持人物性别、年龄、身高、体重、体型、服装、鞋子、配饰、画幅与摄影风格配置；生成两条独立中文提示词；复制与导出 Skill JSON。

## 接入真实智能体与图像服务

此版本仅为静态原型，**没有**连接任何 AI API。上传控件只选择本地文件名，不上传图片，也不执行图片分析。要部署真实产品，建议用 Next.js / FastAPI 创建服务端接口：

1. `POST /api/assets`：上传模特与服装参考图片到受控对象存储。
2. `POST /api/agent/plan`：输入表单参数和素材 ID，返回 MODEL DNA、LOOK DNA、两张独立提示词与验收规则。
3. `POST /api/generate`：分别提交 `flat` 和 `model` 两个独立生成任务，后者引用审核通过的平铺图和模特资产。
4. `GET /api/jobs/:id`：查询生成状态、图片文件地址、失败原因。
5. `POST /api/quality-check`：检查单品一致性、手脚结构、图片尺寸与独立文件数。

API 密钥必须保存在服务端环境变量，不能放入浏览器代码。应设置鉴权、速率限制、成本上限和素材保留/删除策略。生成质量需要人工验收，不能保证100%服装一致性。
